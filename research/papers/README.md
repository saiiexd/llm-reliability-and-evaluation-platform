# Research Papers

This directory contains references to papers that are relevant to the project, along with any legally available summaries, annotations, or links.

## What Belongs Here

- References to papers in a consistent citation format (e.g., BibTeX, APA, or a structured Markdown template).
- Annotations explaining why a paper is relevant to this specific project.
- Legally available open-access PDFs or links to arXiv, ACL Anthology, or similar repositories.
- Personal summaries of key findings, methods, and limitations of each paper.

## What Does Not Belong Here

- Papers downloaded in bulk without review.
- Arbitrary PDFs with no connection to a documented research question.
- Paywalled content that cannot be legally shared.
- Generated AI summaries presented as authored understanding.

## Suggested File Structure

For each paper, either create a single reference entry in a `references.md` file, or create an individual directory per paper:

```
papers/
  references.md          Consolidated list of paper references and links.
  YYYY_author_title/     Optional: individual directory for a paper with annotations.
    summary.md
    notes.md
```

## Relevance Criteria

A paper earns a place in this directory if it directly informs a design decision, evaluation method, metric, dataset, or experimental baseline used in the project.
