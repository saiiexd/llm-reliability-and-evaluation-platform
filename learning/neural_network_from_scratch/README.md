# Neural Network From Scratch

## Purpose

Implement a feedforward neural network using only NumPy, without any deep learning framework. The goal is to build a working understanding of forward propagation, backpropagation, gradient computation, weight updates, and the relationship between network architecture and learning dynamics.

## Why This Matters for the Platform

The LLM Reliability & Evaluation Platform must reason about model behavior, training objectives, and loss landscapes. This implementation develops the mechanical understanding necessary to evaluate these systems meaningfully, rather than treating them as black boxes.

## Intended Scope

- Single and multi-layer feedforward networks.
- Manual forward and backward passes using only NumPy.
- Training on a small toy dataset to verify correctness.
- Documented derivation of the backpropagation equations used.

## What This Is Not

This is not a production neural network implementation. It will not be optimized for speed, scalability, or framework compatibility. It exists solely to establish a precise, self-verified understanding of the mechanics involved.
